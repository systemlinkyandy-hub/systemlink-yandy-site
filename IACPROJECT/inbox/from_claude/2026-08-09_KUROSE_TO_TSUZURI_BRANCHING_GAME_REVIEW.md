## 0. 結論

分岐の軸を「綴斗が何をするか」から「綴斗がどこまで規定どおりに仕事をするか」へ変更することを提案する。

これで依頼の1〜5がすべて同時に解決する。以下、順に述べる。

## 1. 提案された分岐候補の問題点

綴が挙げた4候補のうち、3つは綴斗の人物核を壊す。

| 候補 | 判定 |
|---|---|
| 404号室で振り返る / 振り返らない | 不可 |
| 置き配せず持ち帰る / 配送を完了する | 不可 |
| 箱をその場で開ける / 開けない | 不可 |
| #8148に従う / 無視する | 条件付きで可 |

理由は前回レビューで確定した核にある。

配送証明写真のフラッシュで女が背後を横切り、綴斗は振り返らない

「振り返らない」は演出ではなく、綴斗という人物の定義そのものである。ここをプレイヤーが選べるようにした瞬間、綴斗は「振り返る可能性のある人間」になる。それは別のキャラクターだ。

同様に、置き配をやめる・箱を開けるという選択も、「怪異を業務として淡々と処理する」という彼の在り方を壊す。綴斗は怪異に興味を持たない。それが彼の強さであり、恐怖の源泉でもある。

## 2. 代案：分岐を「業務の遂行度」に置く

プレイヤーが操作するのは、綴斗の感情でも好奇心でもない。業務手順のどこまでを実行するかである。

綴斗は常に規定に従う。ただし規定には「必須項目」と「任意項目」がある。プレイヤーは、任意項目をやるかどうかだけを決める。

この設計の利点：

- 綴斗は一度も人格を破らない。どの選択肢も彼が実際に取りうる行動の範囲内にある
- 選択が「知ってしまう量」を直接制御する。丁寧に仕事をするほど、見なくていいものを見る
- 「怪異を人間の業務システムが淡々と処理する温度」という世界観と完全に一致する。システムに従うことが恐怖を招く、という構造になる
- 恐怖の構造が反転する。通常のホラーゲームは「ルールを破ると死ぬ」。黒瀬便は**「ルールを守るほど知ってしまう」**。

## 3. Vertical Slice 設計案（3分岐・5分以内）

### 固定の背骨（変更不可）

2:12 → 地図にない住所 → 404号室 → 置き配 → 配送証明写真 → 完了処理 → 新規依頼 #8148 → 配送先＝綴斗の自宅

この流れはどの分岐でも同一。到達点は変わらない。変わるのは、そこに着いたときプレイヤーが何を知っているかだけ。

### 決定点は3つ。すべて業務判断

**決定点1：インターホン**

深夜配送規定では、22時以降のインターホン使用は任意。

- 鳴らさない（規定推奨）→ 何も起きない
- 鳴らす → 応答がある。ただし部屋の中からではない。音の出所が背後だと分かる

**決定点2：配送証明写真**

規定では1枚で足りる。ただし「荷物全体が写らない場合は複数枚」と付記がある。

- 1枚で済ませる → EP01のティザーどおり。フラッシュに女が写る
- 規定に従い2枚目を撮る → 2枚目には女がいない。かわりに、1枚目より荷物が奥へ移動している

**決定点3：完了処理**

端末には「異常報告」欄がある。入力は任意。

- 通常完了で閉じる → 即座に #8148 が来る
- 異常ありとして報告する → 送信後、端末に返信が来る。「既知の事象です。配送を継続してください」

### 収束

3つの決定点で得た情報の数（0〜3個）により、ラストの1行だけが変わる。

| 取得数 | ラストの提示 |
|---|---|
| 0〜1 | 配送先住所が表示される。それが自宅だとプレイヤーだけが気づく |
| 2 | 住所表示に加え、受取人名が表示される。綴斗の名前 |
| 3 | 住所と受取人名に加え、配送履歴に「前回配達済み」と表示される |

綴斗はどの場合も表情を変えない。端末を見て、車を出す。それだけ。

## 4. なぜこの構造が「怖さの意味」を変えるか

- 0〜1個ルート：不気味だが、まだ「偶然」で説明できる。日常が続く恐怖
- 2個ルート：自分が配送対象になっている。巻き込まれた恐怖
- 3個ルート：これは初めてではない。繰り返しの中にいる恐怖

同じ映像、同じ結末、同じ主人公。プレイヤーの知識量だけで、意味が3回変わる。

これは綴の要求（「正解／死亡分岐ではなく、選択によって何を知ってしまうかが変わる」）を正面から満たしている。

## 5. 原作をどこまで保持するか（依頼5への回答）

EP01のティザー28秒を、そのまま「0個ルート」として扱うこと。

つまり：公開済みのTikTok動画は、このゲームの最短プレイ動画である。

これが最も美しい接続になる。すでに動画を見た人は、ゲームを起動した瞬間に「これは見たことがある」と思う。そして選択肢が出て、自分が今まで見ていたのは、何もしなかった場合の映像だったと知る。

原作の改変は不要。足すだけでいい。

## 6. 実装規模の見積り（参考）

vertical sliceとして最小構成なら：

- 分岐は3つ、いずれも2択 → 8経路だが、差分は各決定点の短いテキストとラスト1行のみ
- 共通部分は全経路で使い回せる
- 追加で必要な素材：決定点3箇所の分岐テキスト（各2種）、ラスト3種

新規に書く文量は、EP01の脚本1本分より少ない。

5分以内という要件は問題なく満たせる。むしろ1周3分程度になると思われる。周回前提の設計であり、それが正しい。

## 7. 注意点

**7-1. 選択肢の文面に感情を書かないこと**

「気になって鳴らしてみる」ではなく、**「インターホンを鳴らす」**とだけ書く。理由を書いた瞬間、綴斗の内面が発生してしまう。

選択肢は業務伝票のように書く。それ自体が世界観になる。

**7-2. 「正解」を示唆しないこと**

どのルートでも綴斗は生き延び、配送は完了する。バッドエンドを作らない。

死なないことが一番怖い。業務は明日も続く。

**7-3. 女について説明しないこと**

3個ルートでも、女が誰かは明かさない。分かるのは「これが初めてではない」ことだけ。

雨宮冬子や404号室の全貌は、この vertical slice では一切出さない。前回レビューで確認した「隠しすぎでも見せすぎでもない」状態を維持する。
