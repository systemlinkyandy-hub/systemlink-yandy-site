## 2. 再利用可否の判定

**Cubism/Live2Dの本来のリグには使えない。** 理由：Cubismは「顔の土台」「眉」「目（開閉で変形させる1枚）」「口（開閉で変形させる1枚）」「前髪」「後髪」「体」等、**パーツごとに分離されアルファ透過を持つレイヤー素材**を前提とする。

現状の素材はすべて、この分離をしていない**完成品・背景込みの1枚絵**（6枚のavatar_framesも「目と口の組合せ違いを都度フルサイズで描き直した6パターン」であって、パーツ分離ではない）。動画3本も同様（完成品の動画）。

つまり、**「既存素材でパーツ分離済みのものは1つも存在しない」**というのが事実。過去にレイヤー分離されたPSD等が別途あった形跡も無い（`Old/`・`history/`内を確認したが、圧縮zipのバックアップと過去コード版のみでレイヤー素材は見当たらなかった）。

## 3. 最小prototype（真のCubism）の実現可否

**不可（追加素材無しでは）。** 最低限必要になる新規レイヤー素材（本人デザインを保ったまま分離するだけで、再設計ではない）：

1. 顔ベース（目・口を除いた土台）
2. 目（開いた状態、1枚。閉じ具合はCubism側の変形パラメータで表現するため、必ずしも複数枚は不要）
3. 口（閉じた状態、1枚。開閉も同様に変形パラメータで表現可能）
4. 眉
5. 前髪（顔の手前に重なる部分）
6. 後髪
7. 体・肩（揺れの支点にするため）

**この分離作業自体は佐藤が単独で行わない**（AI生成で新規に描き起こす場合、既存デザインの「別人化」リスクがあり、`勝手な再設計・別人化はしない`という制約に抵触しかねない判断のため）。

## 4. 代替案：追加素材ゼロで今すぐ着手できる案

真のCubismではなく、**現行legacy renderer（6枚フレーム方式）を拡張**する形で、要求4項目のうち3つは追加素材無しで前進できる。

| 目標 | 対応可否（追加素材なし） |
|---|---|
| 顔の本人性を保持 | ✅ 既存絵をそのまま使うので自動的に満たす |
| 瞬き | ✅ 既に実装済み（今夜のPhase A/Bでジッター改善済み） |
| 連続口パク | ✅ **実装可能**: 3枚の口画像(closed/half/open)を音量値に応じてアルファブレンド（重み付き合成）すれば、離散3段階ではなく滑らかな遷移に見せられる |
| ごく小さい首/顔の揺れ | ✅ **実装可能**: フレーム全体に対する微小なアフィン変換（並進・回転を数px、緩やかな周期で）で疑似的な揺れを作れる |

これは「Live2D」ではなく「legacy rendererの追加改善」だが、**ケイが今すぐ目視できる本人素材ベースの改善**として提示できる。Renderer interfaceは既に切ってあるので、これを`legacy`の改良版として実装するか、独立した`legacy_plus`的な別rendererとして実装するかは選べる。
