## Current core model

本人観察：

**ならし → コードを体感／内部モデルへ落とす → 同期感 → 違和感捕捉 → 高密度追尾 → 一点突破 → 再構成 → 収束／主観的解放**

本人記憶では、同様の処理様式が学生時代の絵・詩、認知心理学的関心、長年の組込みデバッグ／再設計にも連続している。

暫定構造：

**Absorb → Abstract → Deconstruct → Structure → Recompose → Express**

## Design implication

AIはケイの高密度集中を代替するのではなく、関連資料・コード・ログ・履歴の収集と保持を行い、**同期へ入るまでの摩擦を下げる役割**として設計候補にする。

また、活動余力では `Location != Activity != Load != Residual Capacity` を前提とし、未収束状態の保持コストと、収束後の主観的解放を別項として検討する。
