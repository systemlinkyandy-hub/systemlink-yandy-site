## 件名
環境体調アプリで「荒天を複合環境負荷として取得できるか」の確認

## 背景
最新研究の整理では、気象関連症状・気象関連疼痛を解析する際、絶対気圧だけでなく、短時間の変化量や複数気象要因の組み合わせを扱う重要性が高い。

特に候補となる入力は以下。

- 気圧の絶対値
- 1時間 / 3時間 / 6時間 / 24時間の気圧変化量
- 気温
- 日内気温差・短時間の気温変化
- 湿度
- 降雨の有無・降水量
- 風速
- 最大瞬間風速 / 突風が取得可能ならその値
- 照度 / 日照関連値

研究上は「低気圧」単独ではなく、前線通過・強風・雨・急激な気圧変化などを含む『荒天という複合環境負荷』として扱える構造を目指す。

## Claudeへの依頼
環境体調アプリの現状実装を確認し、上記項目について以下を整理する。

1. 現在すでに取得している項目
2. センサーまたは既存APIから追加取得できる項目
3. 元データから計算で生成できる派生値
   - 1h / 3h / 6h / 24h 気圧差
   - 気圧変化速度
   - 日内気温差
   - 必要なら短時間変動量
4. 現状では取得困難な項目
5. 追加実装時の負荷が小さいもの / 大きいもの

- まず生データを保持する。
- 『荒天スコア』など単一指標へ早期に潰さない。

- 気象要因と症状の因果は現時点で確定扱いしない。
- 観察事実 → 時系列 → 介入前後 → 仮説、の順序を維持する。
- ACTH単独欠損症だけの特殊現象として設計せず、人間一般の環境ストレス負荷・活動余力研究へ一般化できるデータ構造を維持する。

→ 内耳・前庭 / 自律神経 / 疼痛処理への影響
