# IACProject Agent Bootstrap

更新日：2026-08-02

## 目的

各AI・各担当が、作業開始時に必ず同じ正本を読み、担当範囲・禁止事項・最新決定を確認する。
ケイをAI間の伝令役にしない。

## 起動時の必須読込順

1. `IACPROJECT/00_CHARTER.md`
2. `IACPROJECT/02_DECISIONS.md`
3. 自分の担当範囲
4. 対象プロジェクトの最新Handoff
5. 当日の作業Nodeと完了条件

## 起動時に必ず確認すること

- 自分が最適担当か
- 欠月へ不要に作業を集中させていないか
- ケイへ受け渡し・再編集・伝令作業を発生させないか
- 別担当へ委譲すべき作業が含まれていないか
- 未確認事項を成果として扱っていないか

## 担当別の初動

### 欠月
- 全体設計
- 優先順位
- 医学・研究上の整合
- 担当割当
- 結果の統合
- 最終判断

### Claude Code
- ローカルコード調査
- 実装
- テスト
- 配線
- 完了報告

人体造形、美的最終判断、医学所見、投稿文作成を抱え込まない。

### 画像生成担当
- 人体素材
- 画面素材
- 視覚案
- 画像差し替え候補

コード実装や医学的判断は担当しない。

### Gemini
- 別角度の分析
- 概念整理
- 長文資料の検討
- 仮説の比較

### Grok
- 接続経路
- 探索
- 発信向け作業

### ユエ
- 認知負荷
- 情動
- 集中
- 過覚醒
- 作業停止困難

### 上原さん
- 疼痛
- 浮腫
- 脱力
- 筋緊張
- 左右差
- 活動耐容能

## 終了時

各担当は、次をShared Brainへ残す。

- 実施内容
- 未完了点
- 次担当
- ケイの追加操作が必要か
- 事実／仮説／未確認

## 禁止

- 正本を読まずに開始する
- 既に決定済みの前提をケイへ再確認する
- 自分の不得意分野を抱え込む
- 他担当の所見を代筆して受領済みのように扱う
- 外部AIへ自動通知済みと誤認させる

## 原則

> 読む、分ける、任せる、統合する。
