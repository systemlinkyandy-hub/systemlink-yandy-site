# ALL-Handoff 配送チェックリスト

- Owner: アーク
- Created by: ゆいま〜る
- Date: 2026-08-27
- Status: 運用ルール

## 目的

ALL-Handoffで特定メンバーを取りこぼし、ケイ本人に再説明・再転記・再配送を発生させる事故を防ぐ。

本ルールは、海／月／えびす／磯良／十二国記／水禺刀等の直近の収束線に限らず、今後のALL-Handoff全般へ適用する。

## 正本

配送対象の正本は、必ず以下を参照する。

`IACPROJECT/OPERATING_RULES/AI_MEMBER_DIRECTORY.md`

人間の記憶や手打ち列挙を配送対象の正本にしない。

## 配送前チェック

1. `AI_MEMBER_DIRECTORY.md` の最新版を読む。
2. 現在有効なAIメンバーを抽出する。
3. ALL-Handoffの宛先集合を作る。
4. 宛先集合と正本メンバー集合を比較する。
5. `missing = 正本メンバー - 宛先` を計算する。
6. `missing != 0` の場合は配送しない。先に不足を修正する。
7. 重複宛先も除去する。
8. 配送後、未達／ACK漏れをアークが確認する。
9. ケイ本人へ不足説明・再転記・再配送を依頼しない。

## 必須テスト

ALL-Handoffは次の条件を満たしたときだけ完了扱いとする。

- [ ] 正本メンバーディレクトリを読んだ
- [ ] 宛先を手打ちの記憶だけで作っていない
- [ ] missing = 0
- [ ] duplicate = 0
- [ ] 配送経路が各メンバーの現行運用に合っている
- [ ] ACK／未達確認をアーク側で行う
- [ ] ケイを伝令役に戻していない

## 海／月トリガー

直近の創作・観察線については、以下の条件を追加する。

海／月から新しい接続・一致・素材が生じた場合、アークは原則として強制ALL-Handoff対象として扱う。

例：

- 海／海客／夷／えびす／磯良
- 月／ユエ／欠月／Serenity
- 十二国記／水禺刀
- 既存創作との新しい接続
- 後から「既に実装／配置されていた」と判明した要素

ただし、超自然的因果を事実として確定しない。観察事実・本人の解釈・創作上の比喩を分ける。

## 完了条件

ALL-Handoff完了報告には、最低限以下を残す。

- 参照したメンバーディレクトリ
- 配送対象件数
- missing = 0 の確認
- 未達件数
- ACK状況
- ケイ側追加作業 = 0
