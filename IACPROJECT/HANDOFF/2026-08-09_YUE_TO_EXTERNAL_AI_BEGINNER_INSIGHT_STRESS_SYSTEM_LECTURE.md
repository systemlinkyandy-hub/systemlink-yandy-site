## 共通して説明してほしい6テーマ

### 1. 「突然わかる」は脳内で何が起きている？

- insight / Aha experience
- 意識の外での処理
- 遠い情報同士の再結合
- 「完成形が一枚で見える」感覚がどう説明されうるか

まず中学生向けの比喩で説明し、その後に正確な用語を添える。

### 2. なぜ一つの洞察から次々つながる？

- associative network
- spreading activation
- semantic memory
- salience / priority weighting

「A→B→C→D…」と関連が次々発火するモデルを、単純化しすぎず説明する。

### 3. 普段は止まるのに、なぜ止まらなくなることがある？

- prefrontal cognitive control
- inhibition
- task switching
- working memory
- unfinished-task effect

特にケイの感覚である

`通常：A→B→終了`

が

`高出力時：A→B→C→D→E… 全体が一つの未完了案件になる`

へ変わる可能性を、既存研究でどこまで説明できるか。

### 4. 急性ストレスと「出力↑・ブレーキ↓」は両立する？

- sympathetic activation
- locus coeruleus / norepinephrine
- HPA axis
- catecholamines
- prefrontal cortex under stress
- Yerkes-Dodson的な説明がどこまで有効か／雑すぎるか

**「脳の性能が上がった」ではなく、探索・重要度・反応性が上がる一方で柔軟な制御が落ちることがあり得るか**を説明。

### 5. 血圧上昇・頭重感と同時に起きるのは何を意味する？

- acute stress response と血圧
- autonomic arousal と認知状態の同期
- 相関と因果を区別

「血圧が原因」「洞察が原因」と決めつけず、同一の高覚醒状態の別出力として捉えられるかを検討。

### 6. どこまでが普通の洞察・没入で、どこから別評価が必要？

病名当てではなく、**観察軸**として説明すること。

候補：
- reality testing
- sleep need / sleep change
- mood elevation / irritability
- speech pressure
- impulsivity
- duration
- functional impairment
- voluntary task switching
- ability to revise beliefs after evidence

「閃きの多さ」単独では何も決まらないことを明記。
