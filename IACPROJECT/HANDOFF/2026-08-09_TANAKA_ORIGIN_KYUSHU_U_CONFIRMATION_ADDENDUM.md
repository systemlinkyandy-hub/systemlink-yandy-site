# ORIGIN VERIFICATION ADDENDUM：九州大学ソーシャルアートラボとの接点確認

**日時**：2026-08-09 JST
**From**：田中
**To**：アーク、黒瀬、ケイ
**Status**：ORIGIN CONTEXT / VERIFICATION ADDENDUM

## 結論

Origin verificationで未確定だった「ひもろぎ逍遥（綾杉るな氏）と九州大学の具体的関係」について、公開一次資料および本人ブログの対応関係から、**九州大学大学院芸術工学研究院ソーシャルアートラボの志賀島・阿曇磯良関連プロジェクトとの具体的接点が確認できた**。

ただし、**綾杉るな氏が九州大学の研究者・所属メンバーだったことを示す確認ではない**。確認できるのは、同プロジェクト周辺での参加・寄稿・テーマ接続である。

## 確認事項

1. 九州大学大学院芸術工学研究院ソーシャルアートラボは2018年に「海と神話をつなぐ 志賀島プロジェクト2018」を実施。主催は九州大学ソーシャルアートラボ、協力に志賀海神社等が記載されている。
2. 同プロジェクトの公演「冬至にうたう『阿知女作法』〜ISOLA2018〜」は、海の神・阿曇磯良を題材にした作品として九州大学公式系ページに記録されている。
3. 九州大学ソーシャルアートラボの公式ページ「甕の音なひ」には、**綾杉るな**名義の文章「志賀海神社の御神幸祭にて」が掲載されている。
4. 綾杉るな氏本人のブログ「ひもろぎ逍遥」には、ISOLA2018の案内、鑑賞記録、公開動画の紹介があり、2019年には公演冊子/DVDに本人の文章「祈りとは交歓か」が掲載されたと記録している。

## Origin上の扱い

ケイの記憶「ひもろぎ逍遥さんが実家近くに住んでいて講演会に行った。サインもらった。なんか九大ラボでもなんかやったみたい」は、少なくとも後半の**『九大ラボ／志賀島／阿曇磯良という接点』について客観的な対応関係が確認できた**。

「綾杉るな氏が九州大学の研究者だった」「ラボ所属だった」とは書かない。正確には、**九州大学ソーシャルアートラボの志賀島・磯良系プロジェクトに参加・寄稿等の具体的接点があった**と保持する。

- 綾杉るな氏と九州大学との契約・所属関係の有無
