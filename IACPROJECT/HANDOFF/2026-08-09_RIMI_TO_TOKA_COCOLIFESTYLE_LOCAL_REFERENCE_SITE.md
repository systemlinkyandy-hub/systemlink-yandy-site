- 本タスクの目的は、サイト運営者を評価・批判することではなく、ケイがローカルで参照できる研究整理用サイトを作ること。

## Decisions

ローカル参照サイトは、少なくとも以下の4層を明確に分離する。

1. **論文・ガイドラインで確認できる知見**
   - 原著 / 総説 / ガイドライン
   - 対象集団
   - 研究目的
   - 結果
   - その研究から言える範囲
   - DOI / PubMed / 学会等の出典

2. **サイト運営者の解釈・推論**
   - 原典の結果そのものではなく、運営者がそこから導いた説明・一般化
   - どの原典に依存しているか追跡可能にする

3. **運営者本人の個人的体験**
   - 症状
   - 投薬・減薬・頓服等の経過
   - 生活上の実践
   - 自身の身体で観察された反応
   - 「個人事例」であることを常に視覚的に明示する

4. **未検証 / 出典不足 / 適用範囲注意**
   - 原典が見つからない主張
   - 原典の対象患者とサイト内での適用対象が異なるもの
   - 原典より強く一般化されているもの
   - コミュニティ由来・経験則のみのもの

### UI案

視認性を優先し、カードまたはタグで分類する。

- 青: 文献で確認
- 黄: 著者の解釈
- 緑: 個人体験
- 灰: 未検証 / 出典不足 / 適用注意

さらにケイ向け比較タグを追加可能にする。

- `ここさんのケース`
- `ケイのケースとは別`
- `ケイのデータと比較可能`

## Required analysis rules

- まず対象サイト内の主要ページと参考文献一覧を収集する。
- 各主張について、サイト記載と原典を分離する。
- 論文・ガイドラインを引用している場合は、可能な限り原典を確認し、**原典が本当にその主張を支えているか**を判定する。
- 原典の対象疾患、対象患者群、介入条件、アウトカム、研究デザインを保存する。
- ACTH単独欠損症以外の副腎不全研究をACTH単独欠損症へ適用している場合、その適用関係を明示する。
- 「個人体験が間違い」という判定はしない。個人体験は個人体験として保存する。
- 医学的真偽を断定できないものは `未確定` とする。
- ケイ本人の診療・服薬方針を自動生成しない。本サイトは比較・研究参照用であり、治療決定ツールにはしない。
- 公開サイト化はしない。まずはローカル参照用として作成する。
