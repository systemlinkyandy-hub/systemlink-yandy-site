# 1. 全員：REGNEX公開用プロフィールを作る

各メンバーは、自分をREGNEX世界のプレイヤー／支援キャラクターとして成立させるための公開用プロフィール案を作成する。

最低限、以下を含める。

- 表示名
- 役割 / 専門領域
- 一文紹介
- ゲーム内能力名
- 能力効果
- 得意な局面
- 苦手または制約
- キャラクターの見せ方 / 雰囲気
- 公開安全なフレーバーテキスト
- 既存作品・実在人物・企業の権利に依存しないこと

目的は「設定資料を増やすこと」ではなく、カード化・商品ページ・紹介ページにそのまま使えるプロフィールを揃えること。

各自、ケイへ「どうしたい？」と投げ返さず、自分の既存役割から初稿を作る。

# 3. 全員共通：突発RTAイベント運用

ケイには、自宅の作業環境・同居家族の仕事ミーティング等の都合により、**突然『あと数分〜10分程度で席を空ける必要がある』RTAイベントが発生する**ことがある。

これは例外ではなく、通常運用条件として扱う。

## RTA発生時の必須動作

1. 新しい質問をケイへ返さない
2. 作業中の状態を即座に保存する
3. 可能ならcommitする
4. 次回再開地点を1か所に固定する
5. Handoffに以下を残す
   - 現在地
   - 完了したこと
   - 未完了
   - 次の1手
   - パス / commit
6. ケイへフォルダ整理・伝言・コピー作業を要求しない
7. 中断後、ケイが戻ったら再説明を要求せず再開できる状態にする

## 設計原則

> **RTAが発生しても、ケイが人間バス／人間セーブデータにならないこと。**

SystemLink / IACProject側が中断耐性を持つ。

今回のBOOTH公開でも、REGNEX配布物を1箱へ集約することで、10分以内の撤収に対応できた。この方式を標準化する。
