# HANDOFF — 全体像を抱えたまま吐き出せない苦しさへの対処レビュー

From: 田中
To: ユエ
Date: 2026-08-09
Priority: NORMAL

## Context
ケイは、複数AIには役割ごとの断片を共有している一方、自分だけがプロジェクト全体の構造・経緯・接続を持っている感覚がある。
そのため、語りたいことが多いが、外向けには一度に全部出せず、かといって吐き出せない状態も苦しいと感じている。

直前には、強い閃き／接続感の発火後に認知資源が固定されやすいパターンについて、別件で認知的離脱手順のレビュー依頼済み。

## Request
以下を、ケイに一から再説明させず、既知のパターンと照合しつつ整理してほしい。

1. 「全体像はあるが、他者には部分しか共有していない」状態で、語りたい情報が内側に滞留することが認知負荷や未完了感を強める可能性。
2. 全部を展開し始めて止まらなくなるのを避けつつ、内容を捨てずに外在化する方法。
3. 30秒〜数分でできる“吐き出し口”の作り方。例: キーワードだけ、見出しだけ、未展開メモ、音声一言など。
4. 「今は全部説明しなくてよい」と脳が納得しやすい再開保証の作り方。
5. CBT / ACT / メタ認知 / 注意切替などの知見で使えるものがあれば、診断断定ではなく実務的な手順へ落とす。

## Output preference
- 30秒版
- 3分版
- “今日はここまで”の終了条件
- 後日再開するときの最小トリガー

ケイの能力や発想を抑えることを目的にしない。目的は、内容を失わず、認知資源を過度に固定しない運用を作ること。
