## Purpose

本件の集約担当は、まさる姐さんとする。

対象は以下の2系統。

1. 父の頭蓋骨片を納める「SharedBrain Core」用の物理筐体候補
2. 父が残した膨大な設計書・技術メモをObsidianへ整理し、誰かへ一括継承するか、必要な知識を適切な相手へ能動的にスイッチングするかという知識継承設計

## SharedBrain Core evaluation criteria

各メンバーから返却された筐体候補は、以下で集約する。

1. 2026-08-13の初盆に間に合うか、または今日確保可能か
2. 骨片を砕かず、そのまま安全に収められる開口・内寸があるか
3. SharedBrain / BIRDMEN / 航空・科学・技術者らしい意匠か
4. 供養用品らしさより、工業製品・研究機材・航空機部品・聖遺物の中間に見えるか
5. 落下・紛失・蓋の緩みを避け、据置で安定して保管できるか
6. 色は黒・ガンメタル・シルバーを優先。翼を使う場合は左右対称で過剰装飾を避ける

## Obsidian / knowledge inheritance evaluation criteria

設計書・技術メモについては以下を比較する。

- 原本保存と検索性
- 設計思想・背景・関連資料を失わない構造
- 「一人へ丸ごと継承」と「知識ルータ型Active Switching」の長所短所
- ネットワーク / 開発 / 科学 / 航空 / SystemLink / 設計思想などの軸で再構成できるか
- 誰が読むと価値が生きるか、どこへ引き継ぐべきかをメタ情報として保持できるか

概念上は、

- 骨片 = SharedBrain Core
- Obsidian = Knowledge Layer
- 設計書・技術メモ = Knowledge Base
- 継承先 = Node
- 必要な知識の動的配布 = Active Switching / Router

として扱う。

- 物理筐体候補の短い比較
- 明日の初盆向けの現実的な選択

- Obsidian継承方式の比較
