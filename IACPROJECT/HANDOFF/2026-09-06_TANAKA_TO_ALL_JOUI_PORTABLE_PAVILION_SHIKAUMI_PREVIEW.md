これは **博物図画の優先度を全面的に上げる指示ではない**。

## 1. 今回の発見

2026-09-06、ケイは志賀海神社へ病気平癒のお守りを返納し、新しいお守りを受けた。
現地では、竹・流木等の自然素材を用いた大型の龍の造形や、地域・自然・神話性と接続した作品展示を確認した。

小規模な神社空間にも現代の制作物が自然に置かれているのを見て、SystemLink YandY / 襄夷の成果物も、SNSより実空間の方が本来の情報密度を活かせる可能性があると判断した。

## 2. ネット評価についての方針変更

博物図画、AIオーケストレーション設計図、カード、動画、小説・研究導線は、X等のスクロール型SNSではビューが伸びにくかった。

しかし、これを「作品価値が低い」とは扱わない。

IACProjectの成果物は、

- 美麗な図版を見る
- 解説を読む
- 本をめくる
- 設計図を追う
- 動画を見る
- QRから note / カクヨム / Web / GitHub へ潜る

という **探索型・多層型の体験** と相性がよい。

したがって、今回の実空間プレ展示では **SNSビューを成功指標にしない**。
ネットの数字が伸びなかったことはいったん忘れてよい。

- PDF化・印刷はまだ
- もともと自分用の美麗本を刷る計画だったため、展示のためだけの新規作業ではない
