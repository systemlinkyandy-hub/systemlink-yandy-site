# External Sharing Redaction Checklist

外部共有・医療者以外への提示前に確認する。

- [ ] 本人実名・住所・電話・メールを除去
- [ ] 第三者の実名・SNSハンドル・連絡先を除去
- [ ] 医療機関・医療者名は共有目的上必要か確認
- [ ] 位置情報・緯度経度を除去
- [ ] 画像のEXIFやファイル名に個人情報がない
- [ ] 直接引用は必要最小限
- [ ] AI回答を「医療事実」のように見せていない
- [ ] observation / interpretation / inference が分離されている
- [ ] 服薬量等の個人データを一般化していない
- [ ] source_ref から私的ログへ不用意に辿れない
- [ ] 公開版と医療者向け版を分けた
