# Embodied Mapping in Expert Debugging

Personal working name: **Jean-type Debugging / ジーン型デバッグ**

## Purpose

ケイ本人の長期的な自己観察を起点に、熟練デバッグ時の内部表象・身体感覚・構造的再構成・問題収束後の主観的解放を、認知心理学／認知科学の観点から整理する個人研究ノート。

これは「特殊能力」の主張ではなく、**本人観察を一次資料として記録し、既存研究と照合し、仮説として検証可能な形へ整える**ための領域とする。

また、本研究はケイ固有の現象として閉じない。類似した認知様式が、熟練プログラマ、研究者、芸術家、設計者など他者にも存在する可能性を探索する。

## Core observation

本人の熟練デバッグでは、一定出力で長時間コードを読むというより、次のバースト型の過程が自覚される。

1. ならし：コード、ログ、仕様を取り込み、体感／内部モデルへ落とす
2. 同期：コードを記号列ではなく、動く構造として予測可能になる感覚
3. 違和感捕捉：予測と実挙動のズレが突出する
4. 高密度追尾：候補を急速に狭め、一点を短時間で追う
5. 一点突破：原因または構造的欠陥を捕捉する
6. 再構成：必要なら既存構造を分解／破壊し、より整合的に組み直す
7. 収束／解放：問題収束後、主観的な身体的リラックスや体調改善を感じることがある

『CLAYMORE』のジーンが力を「ギリ……ギリ……」と引き絞り、一気に叩き込むイメージが本人の体感に近いため、文化的比喩として「ジーン型デバッグ」と呼ぶ。

## Broader continuity

本人記憶では、この処理様式はプログラミングだけに限定されない。

- 学生時代の絵・詩：概念を取り込み、分解し、最大限に先鋭化した表現として外在化する
- 認知心理学への関心：知覚補完、身体表象、人間をシステムとして理解する試み
- 長年の組込み実務：観測→ログ→再現条件→内部状態推定→構造把握→再設計→実装→試験→収束
- 現在：SystemLink YandY、活動余力、体調環境ログ、AIオーケストレーションへの応用

暫定的な共通構造：

**Absorb → Abstract → Deconstruct → Structure → Recompose → Express**

完成形を保存するより、対象を再生成可能な「構造」まで落とし込む感覚がある、という本人観察を含む。

## Generalisability / population hypothesis

この認知モデルは、現時点ではケイ本人の自己観察を起点とするが、**他者にも類似パターンが存在する可能性を前提に探索する**。

候補となる集団・領域：

- 熟練プログラマ／デバッガ
- 組込み・制御・ネットワーク等、内部状態推定を多用する技術者
- 研究者・設計者
- 絵画・詩・音楽等で、対象を一度内部化し再構成して出力する人
- 身体技法・スポーツ・演奏など、言語化以前の内部モデルや同期感を重視する熟練者

探索したいのは「同じ人がいるか」だけではなく、どの構成要素が共通し、どこが個人差なのかである。

例：

- ならし時間の必要性
- 対象との「同期」感
- 言語ではなく身体／空間的な内部表象
- 違和感の突出と探索空間の急速な縮約
- バースト型の集中
- 分解／破壊後の再構成
- 問題収束後の主観的な解放

### ACTH単独欠損症との関係：探索仮説

ACTH単独欠損症の患者群にも、類似した認知様式を持つ人が存在する可能性はある。ただし現時点では、**ACTH単独欠損症がこの認知様式を生む、または患者群で頻度が高いという根拠はない**。

ここでは二つを分けて考える。

1. **認知様式そのものの存在**
   - 熟練性、個人差、認知スタイル等と関連する可能性
2. **認知活動に伴う身体的変化の可視性**
   - ACTH・コルチゾール系の補償能力が低い集団では、一般には吸収されやすい負荷や状態変化が症状・主観感覚として強く表面化する可能性

したがって、患者群で研究する場合も「患者特有の特殊認知」と仮定せず、**人間一般に存在しうる認知過程が、身体反応とともに観察しやすい可能性**として扱う。

比較対象としては、将来的に患者群だけでなく健常者、慢性疼痛・疲労・感覚過敏など日内変動の大きい群も検討候補とする。

## Research questions

- 熟練プログラマはソースコードをどのような内部表象として保持するのか
- その内部表象は言語的・視空間的・運動的／身体的成分をどの程度含むのか
- 熟練によるchunking、mental model、situation model、predictive processing、analogical reasoning、insight problem solvingとどう対応するか
- 「同期」感は探索空間の縮約や予測誤差の検出とどう関係するか
- 未収束問題を保持することの主観的コストと、問題収束後の解放感はどう記述できるか
- 同じ活動でも、本人の状態・適合度・収束可能性により「消耗」と「回復」の符号が変わり得るか
- 類似したバースト型・身体化された問題解決様式は他の熟練者にも存在するか
- その構成要素は職種横断で共通するか、それとも領域固有か
- ACTH単独欠損症患者において、認知活動と身体反応の対応がより観察しやすい可能性はあるか
- 患者群と非患者群で、認知様式そのものの頻度と、身体反応の可視性を分離して比較できるか

## Information classification

- **確認済み事実**：外部資料、記録、既存文献等で確認可能なもの
- **本人記憶／本人観察**：ケイが長期的に経験・観察してきた内容。消去せず、この区分のまま保持する
- **解釈／仮説**：AIや本人が本人観察と既存研究を接続して作る説明モデル
- **不明**：機序や因果が確認できないものは不明のまま残す

特に、問題収束と身体的リラックス／体調改善との関係は現時点では**本人観察**であり、医学的因果関係が確立しているとは扱わない。

ACTH単独欠損症と本認知様式の関連も現時点では**探索仮説**であり、疾患特異的な認知特性として扱わない。

## Relation to Residual Capacity / 活動余力

このテーマは「作業＝一定の消耗」という単純モデルへの反例候補を含む。

- ならし時間
- 瞬間的な高負荷
- 未収束状態の保持コスト
- 問題収束後の主観的解放
- 同じ活動でも状態・適合度によって負荷が変わる可能性

したがって、Location / Activity / Load / Residual Capacity は分離して記録する。

## AI design implication

AIは集中そのものを代替するのではなく、同期へ入るまでの摩擦を下げる役割として設計候補にする。

例：

- 関連コード・ログ・変更履歴の収集
- 探索候補の保持
- 周辺コードの即時展開
- Handoff／記録／再読可能化
- 本人が捕捉した一点の検証支援
