# cocolifestyle 研究整理（ローカル V2）

公開サイト `cocolifestyle.net` の文章をコピーするのではなく、代表的な主張を4層に分け、原典と適用範囲を追うための静的サイトです。

## 開き方

このディレクトリで次を実行し、表示されたURLを開きます。

```powershell
node server.mjs
```

`index.html` の直接表示ではブラウザの制約でJSONを読めない場合があります。

## V2の範囲

- 優先ページ: ガイドライン2023年版、しっかり補充の誤解、第5回大阪下垂体セミナー、回復の為にできる事、適度な運動の効果、Journal
- 原典照合済み: 日本内分泌学会2023年版、Endocrine Societyの原発性副腎不全／下垂体機能低下症ガイドライン、ESE/Endocrine Societyの薬剤性副腎不全ガイドライン
- 未完: サイト全記事の収集、各記事内の全参考文献照合、CBG・受容体飽和・尿中排泄説明の一次研究までの追跡

V2では、原典名・年・照合位置・サイト内位置・確認日・照合メモ・資料関係を追加しました。病型・病因フィルターと、`pages/audit.html` の出典・照合ログも利用できます。個人体験は「サイト本文との記載照合」と「医学的一般化」を分離しています。

`pages/monitor.html` では、公開サイトと公開アカウントの確認結果を、人物評価から分離して記録します。非公開・削除済み・ログイン時限定の投稿は確認範囲外です。サイト差分は `tools/cocolifestyle-site-check.mjs`、公開アカウント記録は `tools/cocolifestyle-account-check.mjs` で更新できます。

### 追加照合の結論

- CBG: 経口ヒドロコルチゾンの完全吸収と飽和性結合は一次研究で確認できるが、「余分は単純に尿へ排出される」という説明全体は支持されない。
- 運動: 女性Addison病10人の小規模RCTでは短時間高強度運動前10 mg追加の利益はなかったが、別病型や長時間運動へ一般化できない。
- 回復: 薬剤性HPA軸抑制の回復知見は、原因不明例やACTH単独欠損症の回復可能性を直接証明しない。

## 読み方の注意

原発性副腎不全、中枢性副腎不全（ACTH分泌低下症）、薬剤性副腎不全は、共通点があっても同じ集団ではありません。別病型の研究をACTH単独欠損症へ適用する場合は、カードの「言える範囲」を確認してください。本資料は診療・服薬方針を生成しません。
