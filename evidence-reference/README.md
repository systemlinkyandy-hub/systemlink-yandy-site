# 根拠分類リファレンス（一般配布版）

公開情報の主張を「論文・ガイドライン由来の知見」「サイト運営者の解釈」「個人的体験」「未検証・適用注意」の4層に分けて整理するローカル静的サイトです。

原典との関係、照合位置、確認日、言える範囲をカードごとに記録できます。個人的体験の「サイト記載照合済み」と、文献の「原典照合済み」は別表示です。

## 開き方

このフォルダで `node server.mjs` を実行し、ブラウザで `http://127.0.0.1:8766/` を開きます。

## データの編集

`data/claims.json` のサンプルカードを複製・編集してください。配布版には架空のURLと説明用データだけが入っています。実在する対象のURL、氏名、アカウント名、個人情報を公開リポジトリへ登録しないでください。

## 引き継いだ機能

- 4分類の色分け
- 照合状態フィルター
- 6種類の病型・病因表示
- キーワード検索
- 「言える範囲」の明示
- 原典・サイト位置・確認内容・確認日の記録
- 出典・照合ログ

このツールは医学的判断や治療方針を生成しません。
