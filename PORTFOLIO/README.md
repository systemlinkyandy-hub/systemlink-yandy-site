# PORTFOLIO

IACメンバーのIdentity資産・復元元を管理する。

対象例：プロフィール、指示、画像、設定の更新履歴。

サービスUI上の指示欄や画像だけを正本にせず、消失・更新時に復元可能な資産をここへ集約する。

## Member structure (planned)

各メンバー配下で必要に応じて以下を保持する。

- `profile.md`
- `instructions.md`
- `images/`
- 更新・由来情報
