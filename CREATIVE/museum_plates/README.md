# SystemLink 博物図画

博物図画シリーズの専用棚。既存作品を移動する前に目録化する。

## Planned structure

- `canon/` — Style Canon・シリーズ共通ルール
- `catalog/` — 作品目録
- `works/` — 作品単位の資産

作品単位では必要に応じて `final/`, `variants/`, `wip/`, `reviews/`, `prompts/`, `publish/` を使用する。

## Current inventory notes

田中担当情報から、Style Canon v1.1 と既存作例・派生版・投稿記録の棚卸しが必要。v1.2は未確定として扱い、確定正本へ混入させない。

既存物は先にGitHub/Handoff等を検索して目録化し、不足物のみ回収する。
